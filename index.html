Boshoff Bank
Active

A self-hosted household finance manager covering budgets, accounts, pocket money, utilities, and tax-free savings tracking. Runs entirely on local hardware: no cloud, no bank connections, no third party ever touches the data.

Node.jsSQLiteExpressVite

Replaces a household budget spreadsheet the family was already using, so the data model stayed familiar; the project just adds a proper UI and automatic calculations on top of it.

A public-hosting experiment (Fly.io + GitHub) was tried and torn down: Fly.io's free tier turned out not to be free for new accounts. It now runs self-hosted instead, on the home server described below, reachable only from that private network.

Node's built-in SQLite support (Node 22.5+) meant no separate database service to install or back up, just one file. A single shared passphrase gates access rather than full user accounts, since it's one household on one network, not a multi-tenant product.

Personal finance · full-stack 🔒 Private repo

Shopper
Active

A personal price-watching service. Track a watchlist of items across several retailers, get a daily best-price digest by email, and an immediate alert the moment a tracked listing has a substantial price drop.

Node.jsExpressSQLitePlaywright

Each retailer is handled differently based on real testing, not assumptions. Two retailers publish clean structured product data, so a plain page fetch works; their search pages don't return reliable results though, so those two are URL-paste only. A third retailer loads prices client-side, so it needs a real browser (Playwright) to render. Two more block plain requests at the edge entirely, so they stay fully manual: log a price by hand and the same drop-detection logic still applies.

Scraping etiquette mattered from the start: a normal browser user agent only, no header spoofing, no proxies, no CAPTCHA solving, and requests are spaced out. If a retailer starts actively blocking it, the answer is to mark it manual, not to build evasion.

"Best price" is computed per currency rather than mixed together, so a ZAR listing and a USD listing for the same item are never silently compared without a real exchange rate.

Automation · web scraping 🔒 Private repo

Laptop Server
Active

A repurposed laptop turned always-on home server, hosting my personal apps behind a private mesh network. Covers OS setup, networking, power management, and disaster-recovery documentation for the whole box.

DebianShellsystemdTailscale

Debian was chosen for a spare laptop rather than buying a dedicated device like a Raspberry Pi: it puts otherwise-idle hardware to use, and Debian's stability suits something that needs to stay up unattended. It runs headless, lid always closed, on WiFi only.

Every app binds to localhost only; nothing is exposed to the open internet. A private mesh network is the only way in, so access is limited to devices already trusted on that network, not the public web.

There's no UPS and the lid stays closed, so a battery monitor shuts the box down cleanly at 15% remaining rather than letting it hard-cut at 0%. A read-only GitHub deploy key lets the box pull its own updates, rather than holding broader push credentials on a device that's easy to lose track of.

Homelab · infrastructure 🔒 Private repo
